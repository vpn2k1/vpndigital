# Logo-only visual redesign

Owner direction: only the selected VPN Digital logo is used as a brand image across the site. Do not use the former globe/game/software/tools 3D pictures in page content. They remain in public assets for future use and are not deleted.

- Hero, category, and product details: large logo display with radial gradient and subtle CSS orbit lines.
- Category cards: oversized index numerals; product cards: typography and state badges.
- Light Mode uses a **blue-tinted high-contrast surface** rather than an all-white panel, dark blue wordmark, cyan highlights and a stronger border. Dark Mode swaps the logo automatically and uses navy blue.
- Text is intentionally concise and can be expanded later, while preserving verified company information, SEO and "Sắp ra mắt" state.
- Browser test checks that body pages have no other images and that theme switch changes the logo variant.

The sole actual visual image asset in use is `public/brand/vpn-digital/wordmark-{light,dark}.svg`, plus icon/OG for browser metadata. Lucide SVG interface icons are not photos or decorative illustrations.
